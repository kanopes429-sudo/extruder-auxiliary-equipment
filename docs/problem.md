# D01 v2 문제 정의서 — 압출 금형 판 교체

> D01 · 문제 정의서 · 작성 강민구(PM) · 검토 — · 상태 작성 · v2

## 사용자(페르소나)

특수 형상 플라스틱 압출 라인 작업자. 금형 교체 때 1\~2명이 압출기 금형부 앞에서 금형을 200\~300℃로 가열한 뒤, 여러 장을 겹쳐 붙인 금형 판을 한 장씩 떼어 바닥에 내려놓는다. 판은 뜨거워서 맨손으로 잡지 못하고, 위쪽 볼트 구멍에 굵은 렌치를 끼워 그 렌치를 잡고 옮긴다.

## 대상 금형

| 항목 | 값 | 근거 |
|---|---|---|
| 판 장수 | 6장 정도(금형마다 다름) | 추정(근무 경험) |
| 판 크기 | 최대 약 30×20cm | 추정(근무 경험, 기억 기준) |
| 판 두께 | 1cm 내외 \~ 4\~5cm, 전부 합쳐 30cm 이하 | 추정(근무 경험) |
| 판 무게 | 최대 약 20kg (내부 유로 가공으로 꽉 찬 철판보다 가벼움) | 추정(크기와 철 밀도로 계산) |
| 판 결합 | 볼트 여러 개 + 판 양옆의 맞춤 핀(높이 1cm 미만)과 홈 | 근무 경험 |
| 가열 온도 | 200\~300℃ (안의 플라스틱을 녹이기 위해) | 근무 경험 |

## 현재 작업 흐름(As-Is)

① 금형 가열(사람) → ② 위쪽 볼트 해체, 그 구멍에 렌치 끼우기 → ③ 나머지 볼트 해체 → ④ 끝을 뾰족하게 간 플라이로 판 양옆 홈을 쳐서 떼어냄 → ⑤ 렌치를 잡고 판을 받치며 빼냄 → ⑥ 바닥에 내려놓음 → ②\~⑥을 판마다 반복 → ⑦ 내려놓은 판을 가져가 플라스틱 찌꺼기 청소(사람)

판을 받치고 옮기는 ⑤·⑥이 가장 위험한 단계다. 판이 뜨겁고 무거워 떨어뜨리기 쉽다.

## 로봇이 맡을 단계(To-Be)

| 단계 | 맡는 쪽 |
|---|---|
| ① 바깥쪽 판 윗모서리를 집게로 붙잡음 | 로봇 |
| ② 위쪽 볼트 1개 해체 | 사람 |
| ③ 그 구멍에 잠금 핀 삽입(버튼) → 체결 확인 | 사람 → 로봇 |
| ④ 나머지 볼트 해체, 플라이로 판 떼어냄 (로봇은 정지한 채 붙잡음) | 사람 |
| ⑤ "분리 완료" 신호, 작업 영역 이탈 | 사람 |
| ⑥ 판을 축 방향으로 곧게 빼냄(15mm) → 낮은 높이로 이동 → 바닥 구역에 내려놓음 | 로봇 |
| ⑦ 핀·집게 해제 → 다음 판으로 복귀 | 로봇 |

로봇은 렌치를 잡고 판을 받치던 손의 역할을 맡는다. 볼트 해체와 떼어내기는 사람에게 남긴다.

## 불편 지표

| 지표 | 현재 값 | 근거 |
|---|---|---|
| 사람이 받치고 옮기는 판 | 교체 1회 6장, 한 장 최대 약 20kg | 추정(근무 경험) |
| 투입 인원 | 1\~2명 | 근무 경험 |
| 교체 1회 시간 | 미기록 | — |
| 실제로 있었던 위험 | 판을 떨어뜨릴 뻔해 팔로 받치다 화상을 입을 뻔함. 무거운 판을 반복해서 옮기다 허리 부상 | 본인 경험 |
| 금형 낙하 시 손해 | 고가 금형 파손 | 근무 경험 |

## 로봇이어야 하는 이유

| 질문 | 답 |
|---|---|
| 물체를 옮기거나, 움직이거나, 닿나 | 예, 판을 붙잡고 빼내어 옮긴다 |
| 같은 동작을 반복하나 | 예, 판마다(교체 1회 6장) |
| 사람에게 불편·위험한가 | 예, 200\~300℃ 판과 최대 약 20kg 하중. 화상·낙하·허리 부상 |
| 앱·센서·고정 장치로 안 되나 | 안 된다. 판을 물리적으로 받치고 옮겨야 한다 |

## 시뮬레이션에서 잴 것

판 6장 한 판의 시간, 바닥 구역에 놓인 판 수, 낙하 수, 분리 순간 판 처짐(mm), 집게 미끄러짐(mm), 작업자와 팔의 최소 거리(m), 보호 구역 안 팔 이동 횟수

현장 숫자(위 불편 지표)와 시뮬레이션 숫자는 다르다. 시뮬레이션은 판 질량을 축소값으로 두며 하중 능력을 검증하지 않는다. 실물 적용에는 20kg 이상급 협동로봇팔이 필요하다.
