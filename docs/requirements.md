# D03 요구사항 명세 — 압출 금형 판 교체 보조 협동 로봇팔

## ① 요구사항 나누기

| 층 | 내용 |
|---|---|
| Stakeholder | 사람이 뜨거운 판을 받치거나 들지 않고, 판 6장을 떨어뜨리지 않고 바닥에 내려놓는다. 사람은 볼트 해체와 떼어내기만 한다 |
| System | 판 6/6장 순서대로 내려놓음, 낙하 0, 로봇 담당 구간 판당 40초 이하(6장 240초), 작업자 보호 구역 안 팔 이동 0회 |
| Subsystem | 잡기 5초 + 핀 체결 확인 1초 + 빼내기(15mm) 4초 + 이동 15초 + 내려놓기 5초 + 해제·복귀 10초 = 40초. 빼내는 동안 기울기 2° 이하, 분리 충격 때 처짐 5mm 이하 |

시간은 사람이 볼트를 풀고 판을 떼어내는 대기 시간을 뺀 로봇 담당 구간만 센다. 시간 값은 임시이며, 시뮬레이션에서 측정한 뒤 확정한다.

| R-09 | 기능 | 빼내는 동안 판 기울기를 2° 이하로 유지하고, 판이 0.5초 동안 1mm 미만 움직이면 정지하고 기록한다 | Should | 양옆 맞춤 핀 걸림(D01) | T-09 |

| R-11 | 운영 | 실행마다 결과를 `logs/results.csv`에 한 줄 남긴다 | Should | 로그로 원인 파악 | T-11 |

## ③ 우선순위와 범위 밖

| 우선순위 | 내용 |
|---|---|
| Must | R-01 순서대로 6/6, R-02 낙하 0, R-03 판당 40초 |
| Should | R-08 처짐, R-09 기울기·걸림, R-10 이동 높이, R-11 결과 기록 |
| Could | 잠금 핀 있음/없음 비교 실행(미끄러짐 mm), 실제 질량(20kg) 비교 실행, 작업자 반대쪽 경유 경로 선택(간단한 회피) |
| Won't | 온도·열, 녹은 플라스틱 흐름, 볼트 풀기·떼어내기 동작, 카트 이동, 실제 하중, 그리퍼·핀 기구 설계, 안전 센서 모사, 실시간 경로 재계획, 판 청소, 실물 구동 |
| 안전 | R-04~R-07 (늘 지키며 개수에 세지 않는다) |

## ④ 시뮬레이션 설정 메모

- 판 질량: 축소값. UR10e로 들 수 있는 최대 질량을 2kg 단위로 늘려 가며 실험해 정하고, 성공 최대값의 80%를 쓴다. 가장 무거운 판을 그 값으로 두고 나머지는 두께 비율로 줄인다.
- 이 시뮬레이션은 하중 능력을 검증하지 않는다. 실물 적용에는 20kg 이상급 협동로봇팔이 필요하다.
